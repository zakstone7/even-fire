# Assets

Store submission art here. Everything must be **greyscale/monochrome** — Even
rejects colour icon/background assets.

| File | What | Notes |
| --- | --- | --- |
| `icon-foreground.png` | Flame glyph, grey + alpha, 512×512 | Transparent background so it composites on the store/background layer |
| `icon-background.png` | Near-black radial, grey, 512×512 | Opaque background layer |

Both are generated by [`../tools/genicons.py`](../tools/genicons.py) (pure
stdlib, no dependencies):

```bash
python3 tools/genicons.py assets
```

Tweak the flame outline (`SEGS`) or the shading in that script and re-run to
regenerate. These are functional placeholders — replace with polished art before
a public release, keeping them greyscale.
